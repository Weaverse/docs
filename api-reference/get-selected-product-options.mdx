# getSelectedProductOptions

<Note>
  **Hydrogen only.** `@weaverse/hydrogen/next` has no equivalent; a Next.js storefront reads product options from its own route search params.
</Note>

`getSelectedProductOptions` delegates to Shopify Hydrogen 2026.10's utility and removes Weaverse-only query parameters before returning product options.

## Import

```tsx
import { getSelectedProductOptions } from '@weaverse/hydrogen/react-router'
```

## Type

```typescript
function getSelectedProductOptions(
  request: Request
): SelectedOptionInput[]
```

## Filtering

The wrapper removes:

- `isDesignMode`
- Parameters whose names start with `weaverse`

All other parameter names are preserved exactly as they appear in the URL.

## Example

For this request:

```text
https://example.com/products/t-shirt?Color=Blue&Size=XL&isDesignMode=true
```

```tsx
const selectedOptions = getSelectedProductOptions(request)
```

The result is:

```json
[
  { "name": "Color", "value": "Blue" },
  { "name": "Size", "value": "XL" }
]
```

If the URL uses bracketed parameter names, those names remain bracketed:

```text
?option[Color]=Blue&option[Size]=XL
```

```json
[
  { "name": "option[Color]", "value": "Blue" },
  { "name": "option[Size]", "value": "XL" }
]
```

## Loader Usage

```tsx
import { Cache } from '@shopify/hydrogen'
import { getSelectedProductOptions } from '@weaverse/hydrogen/react-router'
import type { LoaderFunctionArgs } from 'react-router'

export async function loader({
  request,
  context,
  params,
}: LoaderFunctionArgs) {
  const selectedOptions = getSelectedProductOptions(request)

  const { data, errors } = await context.storefront.graphql(PRODUCT_QUERY, {
    variables: {
      handle: params.handle,
      selectedOptions,
    },
    cache: Cache.short(),
  })
  if (errors?.length) throw new Error(errors[0].message)

  return { product: data?.product }
}
```
