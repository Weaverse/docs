# useWeaverse

The `useWeaverse` hook returns the active Weaverse runtime. In Hydrogen themes, pass a type argument when you need Hydrogen-specific page data, such as `{ data: WeaversePageData }`. `@weaverse/hydrogen` 6 no longer exports the `WeaverseHydrogen` runtime class.

## Import

```tsx
import { useWeaverse } from '@weaverse/hydrogen/react-router'
```

## Type

```typescript
function useWeaverse<T = Weaverse>(): T
```

## Returns

- `T` — The active Weaverse runtime. It defaults to the core `Weaverse` type.

## Common Use Patterns

### Accessing Component Instances

The `itemInstances` registry maps component instance IDs to their item stores:

```tsx
import { useWeaverse } from '@weaverse/hydrogen/react-router'

export function NavigationControls() {
  const { itemInstances } = useWeaverse()

  const header = itemInstances.get('site-header')
  const announcementBar = itemInstances.get('announcement-bar')

  const toggleAnnouncementBar = () => {
    if (announcementBar) {
      announcementBar.setData({
        isVisible: !announcementBar.data.isVisible,
      })
    }
  }

  const toggleStickyHeader = () => {
    if (header) {
      header.setData({
        isSticky: !header.data.isSticky,
      })
    }
  }

  return (
    <div className="nav-controls">
      <button onClick={toggleAnnouncementBar}>
        {announcementBar?.data.isVisible ? 'Hide' : 'Show'} Announcement
      </button>
      <button onClick={toggleStickyHeader}>
        {header?.data.isSticky ? 'Disable' : 'Enable'} Sticky Header
      </button>
    </div>
  )
}
```

### Accessing Page Data

Pass `WeaversePageData` as the `data` type to get the Hydrogen page data type:

```tsx
import { useWeaverse, type WeaversePageData } from '@weaverse/hydrogen/react-router'

export function PageInfo() {
  const { data } = useWeaverse<{ data: WeaversePageData }>()
  const { id, name, items } = data

  return (
    <div className="page-info">
      <h1>Current Page: {name}</h1>
      <div>Page ID: {id}</div>
      <div>Total Items: {items.length}</div>
    </div>
  )
}
```

## Core Properties

### `itemInstances`

Registry mapping component instance IDs to their item stores.

### `data`

The current project data. In a Hydrogen theme, this is `WeaversePageData`, which includes the page ID, name, root ID, and component items.

### `elementRegistry`

Registry mapping component **types** to their registered component definitions. It is not a registry of DOM elements or component instance IDs.

## When To Use

- When you need to find and interact with components outside the current component tree
- When you need access to page-level runtime data
