# API Reference

The Weaverse SDK provides the runtime, React bindings, framework integrations, and schema utilities used to build Weaverse-powered storefronts.

<Note>
  This section documents the React Router integration, `@weaverse/hydrogen`. Building on Next.js App Router? See the [Next.js API reference](/nextjs/api-reference) for `@weaverse/next`. The hooks `useWeaverse`, `useItemInstance`, `useParentInstance`, `useChildInstances`, and `useThemeSettings` are exported by both packages under the same names.
</Note>

## SDK Packages

### `@weaverse/hydrogen`

The primary package for Shopify Hydrogen applications. It includes:

- `WeaverseClient` for server-side page and theme loading
- `WeaverseHydrogenRoot` for page rendering
- Hydrogen hooks, component types, and utilities
- Re-exports from `@weaverse/react` and `@weaverse/schema`

### `@weaverse/next`

The package for Next.js App Router storefronts. It includes:

- `createWeaverseNextServerClient` (from `@weaverse/next/server`) for request-scoped page and theme loading
- `WeaverseNextRenderer`, `WeaverseNextProvider`, and `WeaverseNextRootProvider` for rendering
- Studio connection, per-item revalidation, and translation utilities
- Re-exports from `@weaverse/react` and `@weaverse/schema`

See the [Next.js API reference](/nextjs/api-reference).

### `@weaverse/react`

React bindings shared by framework integrations, including runtime contexts, hooks, and the lower-level `WeaverseRoot` renderer.

### `@weaverse/core`

Framework-independent runtime classes, item stores, events, and core data types.

### `@weaverse/schema`

Schema definitions, Studio input types, availability types, and validation utilities.

## Basic Usage

```tsx
import {
  WeaverseHydrogenRoot,
  useWeaverse,
  type WeaverseHydrogen,
} from '@weaverse/hydrogen'
import { components } from '~/weaverse/components'

export function WeaversePage() {
  return <WeaverseHydrogenRoot components={components} />
}

export function RuntimeInfo() {
  const weaverse = useWeaverse<WeaverseHydrogen>()

  return <span>{weaverse.data.name}</span>
}
```
