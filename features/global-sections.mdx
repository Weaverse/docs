# Global Sections

A global section is a reusable section you can add to any page in your project. You edit it once, and after you publish it, every page that uses it updates.

## Create a Global Section

1. Add the section to a page and click **Publish** in the topbar. A section must be published before it can be saved as a global section.
2. In the left outline, open the section's action menu and click **Save as global section**.
3. Enter a name.
4. Click **Save global section**.

![Save as global section option in the section menu](/images/global-sections/save-as-global-section-menu.png)

## Use a Global Section

1. In the left outline, click **Add section**.
2. Under **Global sections**, click the section you want. It is added to the page immediately.

Each global section can be added only once per page. A section that is already on the current page is disabled, with the tooltip "This global section is already used in the current page."

## Edit and Publish a Global Section

1. Open any page that uses the global section and edit it like a regular section. The right settings panel shows the section name and how many pages use it.
2. Optional: click **Save section draft** to keep your changes without making them live. You can come back to the draft later from any page that uses the section.
3. Click **Publish section** to update the section on every page that uses it.

The topbar **Publish** button does not publish global section edits. Use **Publish section** in the right settings panel. To throw away saved changes, click **Discard section draft**.

## Manage Global Sections

Open **Advanced features** in the topbar and select **Global sections** to see every global section in your project, how many pages use each one, and when it was created. From this list you can:

- **Rename** a global section.
- **Delete** a global section. Pages that use it keep the content as a regular section, which no longer syncs across pages.
