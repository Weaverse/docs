# @weaverse/hydrogen/next API Reference

The Next.js adapter ships in `@weaverse/hydrogen` (install `@weaverse/hydrogen`) and has two entry points:

| Import | Use in | Purpose |
| --- | --- | --- |
| `@weaverse/hydrogen/next` | Server and Client Components | Registry types, providers, renderer, hooks, Studio connection, translation, schema helpers |
| `@weaverse/hydrogen/next/server` | Server only | The Weaverse API client and the revalidation route handler |

Server code lives under `@weaverse/hydrogen/next/server` so a Client Component can import the root entry without pulling server-only fetch code into the browser bundle.

The root entry is safe in Server Components: its components, hooks and runtime are Client Components (render them, don't call them on the server), and its schema helpers run as ordinary server functions.

<Note>
  `@weaverse/next` is deprecated. Its root and `/server` entries exported more than `@weaverse/hydrogen/next` does: the page, root and commerce data hooks, the lower-level Studio runtime, loader and revalidation helpers, the `ThemeText*` aliases, and the server config and page URL helpers. Only the exports listed on this page are available.
</Note>

## `@weaverse/hydrogen/next`

### Components and providers

| Export | Description |
| --- | --- |
| `createWeaverseNextClient(config)` | Client-side runtime state: registers render components and carries the request, page and theme context. |
| `WeaverseNextProvider` | Provides a client created with `createWeaverseNextClient` to the renderer. Adopts the root theme store when one is mounted above it. |
| `WeaverseNextRenderer` | Renders a Weaverse page tree and binds the Studio runtime. |
| `WeaverseNextRootProvider` | Mount once in `app/layout.tsx`. Owns the theme settings store and translation store for the whole app. Props: `initialThemeSettings`, `themeSchema`, `publicEnv`, `staticContent`, `merchantOverrides`, `t`. |

### Hooks

| Export | Description |
| --- | --- |
| `useThemeSettings()` | Live theme settings; re-renders on Studio edits. See [useThemeSettings](/nextjs/api/use-theme-settings). |
| `useWeaverse()` | The Weaverse runtime. See [useWeaverse](/nextjs/api/use-weaverse). |
| `useItemInstance()` | The current item instance. See [useItemInstance](/nextjs/api/use-item-instance). |
| `useParentInstance()` | The parent item instance. See [useParentInstance](/nextjs/api/use-parent-instance). |
| `useChildInstances()` | The child item instances. See [useChildInstances](/nextjs/api/use-child-instances). |
| `useStudioSelection()` | The current Studio selection, for example `selectedThemeGroup`. `WeaverseNextRootProvider` (or `WeaverseNextProvider`) mounts its store. See [useStudioSelection](/api-reference/use-studio-selection). |
| `isBrowser`, `isIframe` | Environment checks. |

### Studio

| Export | Description |
| --- | --- |

## `@weaverse/hydrogen/next/server`

| Export | Description |
| --- | --- |
| `createWeaverseNextServerClient(config)` | The request-scoped Weaverse API client. Create it per request; see below. |
| `createWeaverseNextRevalidateHandler({ getClient })` | Creates the `POST` handler for per-item revalidation. `getClient(request, requestContext)` receives the validated route context. See [Studio integration](/nextjs/studio#per-item-revalidation). |
| `getWeaverseNextSeoMetadata()`, `formatWeaverseNextSeoMetadata()` | SEO helpers, as above. |
| `getWeaverseStudioCspDirectives(request)` | CSP sources Weaverse Studio needs for this request (6.3.0+); see below. |

Types: `WeaverseNextServerClient`, `WeaverseNextServerClientConfig`, `WeaverseNextServerLoadPageInput`, `WeaverseNextThemeSettingsOptions`, `WeaverseNextThemeSettingsResponse`, `WeaverseNextConfigs`, `WeaverseNextBaseConfigs`, `WeaverseNextCacheConfig`, `WeaverseNextFetchOptions`, `WeaverseNextCustomPageEntry`, `WeaverseNextFetchCustomPagesOptions`, `WeaverseNextProjectId`, `WeaverseNextRevalidateHandler`, `WeaverseNextRevalidateHandlerConfig`, `WeaverseStudioCspDirectives`, the SEO types (`WeaverseNextSeoInput`, `WeaverseNextSeoMetadata`, `WeaverseNextSeoPageContainer`, `NextOpenGraph`, `NextTwitter`), plus the shared types above.

### Server client config

| Option | Description |
| --- | --- |
| `components` | Required. The server registry: schemas and loaders. |
| `projectId` | Project id, or a function returning it. The function receives the `requestContext` and may be `async`; the client awaits it. Falls back to `WEAVERSE_PROJECT_ID`. |
| `weaverseHost` | Studio host. Falls back to `WEAVERSE_HOST`, then `https://studio.weaverse.io`. |
| `weaverseApiBase` | Base URL for public page and settings reads. Overrides `WEAVERSE_PUBLIC_API_BASE`; a trusted Studio host on the request still wins. |
| `weaverseVersion` | Studio asset version. A `?weaverseVersion=` query on the request wins. |
| `env` | Environment object the SDK reads its keys from. A missing key falls back to `process.env`, so `env: process.env` is redundant. |
| `requestContext` | The route identity of this request. |
| `themeSchema` | Your theme schema, for theme settings defaults and Studio. |
| `themeSettings` | Theme settings merged over the schema defaults on the client's `themeSettings`. |
| `commerce` | Commerce context passed to loaders (for example a Storefront client). |
| `cache` | `{ revalidate, tags }` for published reads. |
| `fetch`, `fetchTimeoutMs` | Custom fetch and timeout (default 10 seconds). |

### Server client members

| Member | Description |
| --- | --- |
| `loadPage({ type, handle?, locale?, projectId?, cache? })` | Fetches the page, runs component loaders, and returns `WeaverseNextLoaderData`. `locale` selects the assigned page's locale, `projectId` overrides the project for this call, and `cache` (`{ revalidate, tags }`) is merged over the client-level `cache`. Never throws: an unassigned route resolves to a placeholder page whose `page.id` starts with `fallback_page_`, and a missing project ID or failed request resolves to `null`. See [Rendering pages](/nextjs/rendering-pages#no-page-means-404). |
| `loadThemeSettings()` | Fetches theme settings merged over schema defaults. Returns `theme`, `schema`, `staticContent`, `publicEnv` in design mode, and `merchantOverrides` when the theme declares `i18n` and the request carries a language and country. |
| `fetchCustomPages(options?)` | Lists the custom pages assigned in the project for a sitemap, paginating automatically. Not filtered by publication state; see [Custom pages in the sitemap](/nextjs/rendering-pages#custom-pages-in-the-sitemap). |
| `fetchWithCache(url, options?)` | Next-aware fetch: `no-store` in design and revision preview, `next: { revalidate, tags }` in published mode. |
| `projectId`, `resolveProjectId()` | The project id; `resolveProjectId()` resolves it asynchronously (query, function, string, env). |
| `components` | The server registry. |
| `commerce`, `storefront` | The commerce context; `storefront` is an alias for Pilot-style loaders. |
| `requestContext` | URL, headers, search params, i18n and design/preview flags. |
| `configs` | The resolved configuration. |

### Config resolution

- **Project id**: `?weaverseProjectId=` → `projectId` function → `projectId` string → `WEAVERSE_PROJECT_ID`.
- **Studio host**: trusted `?weaverseHost=` (`https://*.weaverse.io`, `https://*.weaverse.dev`) → `WEAVERSE_HOST` → `https://studio.weaverse.io`.
- **API base**: trusted request host → `WEAVERSE_PUBLIC_API_BASE` → non-production `WEAVERSE_HOST` → `https://api.weaverse.io`.
- **Public env**: `PUBLIC_STORE_DOMAIN`, `PUBLIC_STOREFRONT_API_TOKEN`.

### `getWeaverseStudioCspDirectives`

```ts
import { getWeaverseStudioCspDirectives } from '@weaverse/hydrogen/next/server'

function getWeaverseStudioCspDirectives(
  request: Request | URL | string,
): WeaverseStudioCspDirectives
```

Available in `@weaverse/hydrogen` 6.3.0 and later. Returns the CSP sources Weaverse Studio needs for this request, shaped like Hydrogen's `ContentSecurityPolicyDirectives` so you can append them to your directives before calling `createContentSecurityPolicy` (`@shopify/hydrogen` 2026.10.3+):

- `{}` for normal visitors, and for a relative or malformed URL.
- On Studio requests (design mode, section preview or revision preview) with a trusted `weaverseHost` (`https://` on `weaverse.io` or `weaverse.dev`): the Studio origin in `frameAncestors`, `scriptSrc`, `connectSrc`, `styleSrc`, `fontSrc` and `imgSrc`. Design mode adds `'unsafe-eval'` to `scriptSrc`.
- `{}` for an untrusted `weaverseHost`, so a crafted URL can't widen the policy.

The same function is exported from `@weaverse/hydrogen/react-router`; see [`getWeaverseStudioCspDirectives`](/api-reference/get-weaverse-studio-csp-directives). For a full setup, see [Studio integration](/nextjs/studio#content-security-policy).
