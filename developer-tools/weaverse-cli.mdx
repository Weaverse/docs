For developers crafting Weaverse Hydrogen themes, the Weaverse CLI is a simple yet powerful aid, streamlining project
setup and management tasks directly from the command line.

## Installation & Usage

You can run the CLI directly using **`npx`** to ensure you're always using the latest version:

```txt data-line-numbers=false
npx @weaverse/cli@latest [command]
```

To view available commands and options:

```txt data-line-numbers=false
npx @weaverse/cli@latest --help
```

## Available Commands

### `create`

The `create` command is essential for starting new Weaverse Hydrogen projects. It:

- Creates a new project directory
- Downloads and extracts the selected template
- Sets up environment variables, including your `WEAVERSE_PROJECT_ID` and a generated `SESSION_SECRET`
- Installs necessary dependencies (optional)
- Starts the development server (optional — prompted interactively, opt-in with `--dev` in non-interactive runs)

#### Available Templates

Weaverse CLI currently supports the following templates:

| Template | Description |
| --- | --- |
| **pilot** | A fully-featured Shopify Hydrogen theme for modern headless storefronts |
| **naturelle** | A beauty and lifestyle-focused Shopify Hydrogen theme |
| **aspen** | A sophisticated theme for home furniture and interior design stores |
| **maison** | A modern B2B theme for furniture wholesalers, distributors, and interior design brands |

#### Options

| Option | Description | Required | Default |
| --- | --- | --- | --- |
| **`--template`** | Template name (`pilot`, `naturelle`, `aspen`, or `maison`). Prompted in interactive mode; must be passed in non-interactive mode | Yes | - |
| **`--project-id`** | Your Weaverse project ID. Prompted in interactive mode; must be passed in non-interactive mode | Yes | - |
| **`--project-name`** | Name for your project directory. Prompted in interactive mode; defaulted when omitted in non-interactive mode | No | Prompted / defaulted |
| **`--commit`** | Specific Git commit hash to use | No | Latest from main branch |
| **`--no-install`** | Skip dependency installation and dev server start | No | false |
| **`--dev`** | Start the development server after install. Use `--no-dev` to skip the prompt and not start it | No | Prompted (interactive) / off (non-interactive) |
| **`-y`, `--yes`** | Non-interactive mode: never prompt, fail fast on missing required options | No | false |
| **`--ci`** | Alias for `--yes` | No | false |
| **`-f`, `--force`** | Overwrite the target directory when it already exists | No | false |

<Note>
  The CLI also runs non-interactively on its own when stdin isn't a TTY (piped
  input, CI, or a coding agent), or when `CI=true` is set — `--yes`/`--ci` just
  force that mode explicitly.
</Note>

#### Usage Examples

**Basic usage with the Pilot template:**

```txt data-line-numbers=false
npx @weaverse/cli@latest create --template=pilot --project-id=clocwvm3y08j2r79n3c44uhjh --project-name=my-store
```

**Using the Naturelle template:**

```txt data-line-numbers=false
npx @weaverse/cli@latest create --template=naturelle --project-id=clocwvm3y08j2r79n3c44uhjh --project-name=naturelle-store
```

**Using a specific commit version:**

```txt data-line-numbers=false
npx @weaverse/cli@latest create --template=pilot --project-id=clocwvm3y08j2r79n3c44uhjh --commit=a1b2c3d4
```

**Creating project without installing dependencies:**

```txt data-line-numbers=false
npx @weaverse/cli@latest create --template=pilot --project-id=clocwvm3y08j2r79n3c44uhjh --no-install
```

**Agent/CI-friendly setup:**

```txt data-line-numbers=false
npx @weaverse/cli@latest create --template=pilot --project-id=clocwvm3y08j2r79n3c44uhjh --project-name=my-hydrogen-storefront --no-install -y
```

**Non-interactive setup that also starts the dev server:**

```txt data-line-numbers=false
npx @weaverse/cli@latest create --template=pilot --project-id=clocwvm3y08j2r79n3c44uhjh --project-name=my-store --dev -y
```

## Workflow

When you run the `create` command, the CLI will:

1. Download the selected template from GitHub
2. Extract the template to your specified project directory
3. Configure environment variables (including your Weaverse project ID)
4. Generate a secure local `SESSION_SECRET`
5. Install dependencies using npm (unless `--no-install` is specified)
6. Start the development server — in interactive mode the CLI asks first; in
   non-interactive mode it only starts when `--dev` is passed, so agent and CI
   runs return instead of hanging on a blocking server

<Warning>
  `npm run dev` is a long-running, blocking process. Leave `--dev` off in CI and
  agent-driven runs, then start the server yourself with `cd my-store && npm run dev`.
</Warning>

After completion, you'll see instructions for the next steps to take.

## Troubleshooting

### Common Issues

**Template Download Fails**
- Check your internet connection
- Verify that the specified commit hash is valid (if using `--commit`)
- Try again with the default template without specifying a commit

**Dependency Installation Fails**
- Try running `npm install --legacy-peer-deps` manually in the project directory
- Ensure you have a supported version of Node.js installed. The current Pilot template declares Node.js `>=22.12.0`; the `@weaverse/hydrogen` package itself declares Node.js `>=20`
- Check for errors in your project's package.json

**Development Server Won't Start**
- Make sure all required environment variables are set
- Stores on a Shopify plan: install the Hydrogen sales channel (https://apps.shopify.com/hydrogen), create one Hydrogen storefront project, then run `npx shopify hydrogen env pull`. If needed, copy values from **Hydrogen sales channel → Storefront Settings → Environments and variables**.
- Development stores or stores without a Shopify plan: install the Headless sales channel (https://apps.shopify.com/headless), then copy the Storefront API values into `.env`.
- Verify port 3456 is available on your system
